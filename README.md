# ちいさな勇者と くらやみの洞窟

ファミコン時代の初期RPGをイメージした、ブラウザで遊べる1画面ミニゲームです。

> 特定作品の画像・音楽・シナリオ・固有名詞は使用せず、8ビットRPGの雰囲気を参考にしたオリジナル作品です。

## 遊び方

1. 方向ボタン、またはPCの矢印キーでフィールドを移動します。
2. 草原や森を歩くと、ランダムで敵が出現します。
3. `たたかう`、`じゅもん`、`やくそう`、`にげる`から行動を選びます。
4. 敵を倒して経験値をため、レベル4を目指します。
5. マップ南東の洞窟へ到達するとゲームクリアです。

城に戻るとHPとMPが全回復します。`きろく`でブラウザに保存し、`つづき`で再開できます。

## 主な機能

- スマートフォン対応の方向キーUI
- キーボードの矢印キー操作
- 草原・森によるエンカウント率の違い
- 通常攻撃、攻撃魔法、回復アイテム、逃走
- 経験値、レベルアップ、HP・MP成長
- 戦闘不能時の城への帰還と所持金ペナルティ
- `localStorage`によるセーブ・ロード
- レベル条件付きのゲームクリア

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 本番ビルド

```bash
npm run build
npm run start
```

## 技術構成

- Next.js 14
- React 18
- CSSのみで描画したレトロ風UI
- 外部画像・音源・追加ライブラリなし
