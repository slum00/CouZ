# CouZ - Simple Mobile Web App

このリポジトリは、**Next.js最小構成**で作成したスマホ向けシンプルWebアプリです。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くとトップページが表示されます。

## 含まれる内容

- Next.js (App Router) の最小構成
- トップページ (`app/page.js`)
- モバイル向けのシンプルなUI (`app/globals.css`)
